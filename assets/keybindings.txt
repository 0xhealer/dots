Keybinds -- Hyprland and niri (Mod = Super)

  Mod + T / Return          Terminal (kitty > ghostty > foot, whichever is installed)
  Mod + Shift + Return       Terminal: ghostty
  Mod + Ctrl + Return        Terminal: foot

  Mod + D / Space           Launcher (Rofi: apps)
  Mod + Shift + D            Rofi: run command
  Mod + Shift + Space        Rofi: window switcher

  Mod + W                   Pick a wallpaper -> palette of every app updates
  Mod + Shift + W            Random wallpaper -> palette of every app updates

  Mod + M                   Music (Spotify -- manual install)
  Mod + E                   File manager (Thunar)
  Mod + B                   Browser (Helium > Brave > Firefox)

  Mod + F                   Fullscreen toggle
  Mod + Q                   Close window
  Mod + V                   Toggle floating

  Mod + Tab                 Lock screen (Noctalia, if installed)
  Mod + Escape              Control center (Noctalia, if installed)

  Hyprland:  Mod + Delete   Screenshot, full (grim)
             Delete         Screenshot, region (grim + slurp)
  niri:      Print          Screenshot;  Alt + Print: window

  Mod + 1..4                Switch workspace 1-4
  Hyprland:  Mod + Shift + 1..4    Move window to workspace
  niri:      Mod + Ctrl + 1..4     Move column to workspace

  Mod + Shift + Slash       Show this cheatsheet (niri: built-in overlay)
